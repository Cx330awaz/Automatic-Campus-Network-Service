# 校园网 Wi-Fi 自动登录

登录 Windows 桌面时自动完成：连接 `JOU` → 打开认证门户 → 填入账号密码 → 选择运营商 → 自动关闭浏览器。

## 使用步骤

**0. 生成配置文件**

```bash
cp config.ini.example config.ini
```

然后填入账号密码和运营商。`config.ini` 已在 `.gitignore` 里，不会被提交。

**1. 手动跑一次**

```bash
python auto_login.py --debug
```

`--debug` 会把日志同时打到控制台，方便看每一步的状态。

**2. 选一种方式装自启**

*方式一（推荐）*：右键 `安装开机自启.bat` →「以管理员身份运行」。
它自己也会检测权限并弹 UAC，所以双击也行。建的是"登录时触发 + 延迟 25 秒"的计划任务，延迟是为了等 Wi-Fi 协议栈就绪。

*方式二（免管理员）*：双击 `备用-启动文件夹自启.bat`。
在"启动"文件夹放一个快捷方式。代价是没有延迟，会比方式一更早开始跑 —— 脚本自身最多会等 45 秒 Wi-Fi，通常没问题。

## 工作原理

1. `netsh wlan connect` 连接 JOU，之后轮询直到网络有响应
2. 用 `Microsoft Connect Test` / `generate_204` 探测：返回 204/200 说明已联网；返回 302 说明被劫持到门户，从 `Location` 头拿到门户地址
3. Selenium 驱动浏览器打开门户，选择运营商，填账号密码并提交
4. 重新探测网络，确认真的通了，再关闭浏览器，并顺手关掉 Windows 自己弹出的那个门户页

探测返回 204 就表示已经在线，所以**已经登录时脚本会直接退出**，不会重复提交。

## 常见问题

**浏览器没起来 / 报驱动错误**

Selenium 需要 `msedgedriver` 或 `chromedriver`。开机时还没联网，Selenium Manager 无法下载驱动，脚本会自动切到离线模式读本地缓存。

两个驱动都已在本机预热好（`C:\Users\31967\.cache\selenium\`）。**但如果浏览器自动更新到新版本，缓存的驱动会失效**，此时需要手动联网跑一次 `python auto_login.py` 让它重新下载。

实在起不来时脚本会退化成用系统默认浏览器打开门户页，你手动点一下即可。

**填进去了但登录失败**

加 `--dump` 跑一次，把 `debug/portal_xxxx.html` 发出来，可以针对该门户写精确的选择器。目前用的是通用启发式规则（找可见的 text 输入框填账号、`type=password` 填密码、找提交按钮），对绝大多数校园网门户够用，但对纯 JS 渲染的门户可能需要微调。

**登录完成后，屏幕上还留着一个登录页网页**

这不是脚本开的窗口，是 **Windows 自己弹的**。

连上强制门户时，Windows 的 NCSI 会探测到"被劫持到登录页"，于是用**系统默认浏览器**
弹一个门户窗口。它不归 Selenium 管，`driver.quit()` 关不掉，所以登录完成后就留在桌面上。

脚本现在会自己收拾它：登录成功后，按下面的顺序找那个窗口并关掉——

1. **进程命令行里带着门户域名** —— 铁证。Windows 是 `chrome.exe "http://<门户>/…"`
   这么拉起浏览器的，你日常开的 Chrome 命令行里不会有门户地址。
2. **窗口标题命中门户页** —— 脚本会把自己读到的门户页标题（本机是「上网登录页」）
   拿来比对。注意标题会随页面跳转变化，所以这条只是补充。
3. 其余"脚本开跑后新冒出来"的浏览器窗口 —— **只记日志、不关**，因为无法确认是不是
   门户，宁可漏关也不误伤你自己的标签页。

跑完可以搜日志里的 `关闭 Windows 自动弹出的门户窗口` 确认有没有生效。不想让它插手就设：

```ini
[browser]
close_portal_window = false
```

如果日志里出现"无法确认是不是门户（标题=…）"，说明那个窗口的标题和命令行都没能
对上——把它发出来，可以在 `PORTAL_TITLE_HINTS` 里补上对应的字样。

**不想看到浏览器窗口**

`config.ini` 里设 `headless = true`。

**为什么 .bat 里全是英文提示？**

cmd.exe 有个已知缺陷：它按**字节偏移**读取 bat 文件，遇到多字节字符（中文）时会按字符数错误重定位，导致后面的语句被乱读、执行顺序错乱。所以给 cmd 执行的 bat 必须是纯 ASCII。中文提示都在 `auto_login.py` 里（Python 正确处理编码），那个不受影响。

## 注意

- 密码以明文存在 `config.ini` 里（自动登录必须如此）。仓库里只有不含凭据的模板
  `config.ini.example`，真正的 `config.ini` 已被 `.gitignore` 排除——但传到网盘、
  压缩包或聊天工具时仍要自己留意。
- 脚本只在探测不到网络时才动作，不会干扰你手动登录。
- 日程任务名 / 快捷方式名固定为 `CampusWiFiAutoLogin`（同为 ASCII 原因）。

**另：可以修改安装开机自启.bat中 39行的'00:00:15'以修改进系统后脚本运行的等待时间（根据自己开机速度自行修改，建议不低于00:00:10，概率出错）
